Data Entity Schemas: Game Class (POCO Model)

This class acts as a Plain Old CLR Object (POCO) that maps directly to the underlying physical PostgreSQL database schema using Entity Framework Core attributes.

Class-Level Attributes

  • [Table("games")]
    What it does: Explicitly maps the Game C# class to a physical database table named games. Without this, EF Core would default to naming the table after the property name (usually Games).

Properties & Property-Level Attributes

  • [Key] & [Column("game_id")] public int GameId { get; set; }
    What it does: [Key] marks this property as the Primary Key for the table. [Column("game_id")] ensures the field maps to the exact column name in PostgreSQL. The int type ensures automated incremental sequencing.
  • [Column("title")] public string Title { get; set; } = null!;
    What it does: Maps the property to the title column. The = null!; syntax uses the null-forgiving operator to satisfy C# nullable reference types, indicating this field must contain valid string data upon initialization.
  • [Column("hours_played")] public decimal HoursPlayed { get; set; }
    What it does: Maps to the hours_played column. Using decimal is standard practice for numeric data fields requiring exact fractional precision (like gameplay trackers) rather than floating-point approximations.
  • [Column("release_date")] public string? ReleaseDate { get; set; }
    What it does: Maps to the release_date column. The ? suffix marks this property as nullable, meaning the database can store an empty or missing value for this field.
  • [Column("completion_status")] public string? CompletionStatus { get; set; }
    What it does: Maps to the completion_status column. It is safely marked as a nullable string reference type to gracefully handle incomplete backlogs.
  • [Column("metascore")] public int? Metascore { get; set; }
    What it does: Maps the C# property to the newly added database column metascore. By defining it as int? (nullable integer), it accommodates games that lack an official review rating.
  • public List<Genre> Genres { get; set; } = new();
    What it does: Establishes a navigation property defining a relationship with the Genre entity. EF Core interprets this list to configure relational mappings (such as a Many-to-Many join table configuration) behind the scenes.
